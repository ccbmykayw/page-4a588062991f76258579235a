品牌简介

灯塔是面向个人与团队的网络加速服务品牌，提供机场订阅与 VPN 梯子能力。我们把重点放在线路可用性、客户端兼容和说明文档的可读性上，而不是堆砌口号。用户完成套餐开通后即可获得订阅地址，导入 Clash、Shadowrocket、Stash、Clash Meta 等常用客户端，按延迟与用途选择节点。

作为灯塔官方网站信息页，本站集中说明套餐差异、设备台数、流媒体与游戏线路特点，以及从下载客户端到导入订阅的完整步骤。灯塔节点覆盖香港、日本、新加坡、美国及部分欧洲城市，旗舰与团队线路含 IPLC 优化，适合对延迟更敏感的场景。请通过正规渠道获取订阅，避免来路不明的配置文件。

客户端选择与官方下载指引

灯塔以订阅为核心，不强制安装单一封闭软件。请先根据系统选择成熟客户端，再导入官方订阅。下列说明用于官网下载与配置对照，安装包请从各客户端项目或应用商店获取，勿轻信来路不明的打包文件。

Windows

推荐 Clash Verge、Clash for Windows 或同类图形界面。安装后打开订阅栏，粘贴灯塔提供的 URL，更新节点后选择规则模式或全局模式连接。适合同时处理网页、会议与下载。

macOS 与 Linux

macOS 可使用 ClashX、Stash 或 Surge；Linux 常用 Clash Meta 命令行或兼容面板。导入方式与 Windows 类似，注意系统代理与 TUN 模式权限。

Android

推荐 Clash Meta for Android 或 v2rayNG。从官方发布渠道安装，添加订阅后开启分应用代理，可避免国内应用绕行。旗舰节点更适合需要稳定带宽的移动办公。

iOS

常用 Shadowrocket、Stash、Quantumult X。客户端需自行在商店购买。添加灯塔订阅后按策略组分流：国内直连、流媒体走解锁节点、游戏走 IPLC。

完成客户端选择后，回到用户中心复制订阅链接即可。本页操作说明提供逐步核对清单。

使用场景

跨境远程办公

会议、网盘与企业邮箱对稳定性要求高。灯塔普通线路可满足网页与文档，旗舰 IPLC 更适合长时间视频会议，减少抖动。

流媒体观看

旗舰版强调全节点原生解锁，便于访问常见影视与音乐平台。若某个节点未解锁，切换同区域其他节点即可，无需更换套餐。

游戏加速

团队版与旗舰版提供游戏向优化线路，降低到部分区服的往返时延。实际体感仍受本地宽带与高峰拥塞影响，建议先用小流量测试。

学术与公开资料

基础版流量适合论文检索、公开课与代码仓库访问。注意遵守目标网站条款与所在地法规，灯塔仅提供连通性。

多设备家庭或小团队

设备数是硬限制：3 / 5 / 20 台。家庭共用选旗舰，工作室或实验室选团队版并规划路由，避免互相抢占会话。

操作说明

开通与获取订阅

  1. 在套餐区确认流量、设备数与是否需要 IPLC 或原生解锁。
  2. 完成支付后，于用户中心查看订阅 URL，建议同时保存备份。
  3. 不要在公开群组粘贴完整订阅，防止被盗用导致流量异常。

导入与连接

  1. 按「客户端选择」安装对应加速器。
  2. 在订阅或配置页粘贴灯塔 URL，执行更新。
  3. 观察延迟与最近一次成功握手时间，优先选近期活跃节点。
  4. 网页浏览可用规则模式；需要整机走代理时再开 TUN 或系统代理。
  5. 若无法上网，先关闭系统代理冲突软件，再核对本地时间与规则集。

日常维护

建议客户端开启定时更新订阅。更换套餐后旧链接可能失效，需重新导入。流量与在线设备可在灯塔用户中心核对，不必反复重装软件。

节点与性能说明

灯塔将普通线路与专线分开标注。基础版以覆盖面为主，适合浏览与轻量下载；旗舰与团队在热门方向增加带宽与 IPLC，晚高峰仍可能波动，但可切换备用节点。我们不承诺固定毫秒数，请以客户端实时延迟为准。工单优先响应旗舰与团队用户，说明操作系统、客户端名称与失败节点即可加快排查。

常见问题

灯塔是 VPN 还是机场订阅？有何区别？

灯塔同时提供机场订阅能力与多端加速体验。与单一入口的传统 VPN 不同，用户可在多个节点间切换，并自由选择 Clash、Shadowrocket 等客户端。套餐按流量与设备数计费，更适合需要分流和多场景切换的人。

客户端应该从哪里下载才安全？

请从各客户端官方仓库、开发者站点或正规应用商店获取。灯塔官网提供导入与策略说明，不捆绑第三方安装包。收到要求在聊天工具下载「破解版加速器」的消息应直接忽略。

如何把灯塔订阅导入到手机和电脑？

购买后复制订阅地址，在客户端的「订阅 / 配置 / 添加 URL」中粘贴并更新。同一订阅可在套餐允许的设备数内使用。iOS 需先自行购买 Shadowrocket 或 Stash 等应用，再导入。

流量是单向还是双向？用完会怎样？

按实际上行与下行合计计算。基础版 100GB、旗舰 300GB、团队 1000GB，周期重置。用尽后连接可能降速或中断，可升级套餐。用户中心可查看已用流量，避免月底突然耗尽。

同时在线设备超过限制怎么办？

基础版 3 台、旗舰 5 台、团队 20 台。超出后新设备可能无法握手，已连接会话也可能被挤下。家庭共用请规划谁在线；团队版适合多成员并提供定制路由。

流媒体和游戏分别该选哪档？

轻度解锁与浏览可选基础版；需要全节点原生解锁和更好晚高峰表现选旗舰版；多人共享、高带宽或要专属客户经理选团队版。游戏请优先尝试标注 IPLC 的节点。

节点经常变动，需要天天手动更新吗？

灯塔会调整线路与入口，建议在客户端打开自动更新订阅，或每天手动更新一次。若某节点连续失败，换同区域其他节点即可，不必反复重装客户端。
